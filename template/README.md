# วิธีใช้งานโฟลเดอร์ Template (Drop & Go)

คุณไม่ต้องตั้งชื่อรูป ไม่ต้องครอปรูป และไม่ต้องเขียนสคริปต์เองครับ
แค่ทำ 2 อย่างนี้:

1. **Duplicate / สร้างโฟลเดอร์ใหม่** โดยตั้งชื่อเป็นรหัสหรือชื่อสินค้า (เช่น `#130_ชื่อสินค้า`)
2. **โยนรูปสินค้า 3–10 รูป** ลงในโฟลเดอร์นั้นได้เลย (รูปจากหน้า Shopee, รูปสวอชสี, รูปนางแบบ, หรือรูปใช้งานจริง — มีตัวหนังสือจีน/ไทยติดมาได้ เดี๋ยวระบบคัดและครอป/เจนใหม่ให้เอง)
3. *(ไม่บังคับ)* แก้ไฟล์ `brief.txt` สั้นๆ แค่ 1–3 บรรทัด ถ้ามีจุดขายที่อยากเน้นเป็นพิเศษ หรือลิงก์ Shopee สำหรับทำแคปชั่น

---

## สิ่งที่ระบบจะตัดสินใจและทำให้เองอัตโนมัติ
- **อ่านข้อมูลจากรูป:** ดึงชื่อแบรนด์, ชื่อรุ่น, เฉดสี, เนื้อสัมผัส, และวิธีใช้จากภาพโดยตรง
- **คัดและอัปเกรดภาพ:**
  - รูปไหนใช้ได้ → ครอปตัดขอบข้อความ/ลายน้ำให้สะอาด
  - รูปไหนใช้เปิดคลิปไม่สวย/ตัวหนังสือรก → สั่ง AI เจนภาพ `9:16` ใหม่ให้เนียนระดับโฆษณา
- **คิดบทและจัดหน้า:** เลือกมาสคอต, โทนสี, พาดหัว, จุดเด่น 3 ข้อ, วงแหวนชี้สี (ถ้ามีชาร์ตสี), พากย์เสียง, ซับคาราโอเกะ, ปรับเสียง `-14 LUFS`, และอัปโหลดคลิปส่งงานให้ทันที
